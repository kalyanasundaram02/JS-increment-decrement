# JavaScript Counter App

A simple counter application built using HTML, CSS, and JavaScript. This project demonstrates basic JavaScript DOM manipulation and event handling.

## Features

- **Increase:** Increments the counter by 1.
- **Decrease:** Decrements the counter by 1.
- **Reset:** Resets the counter to 0.
- **Interactive UI:** Buttons with CSS hover and transition effects.

## Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling, gradients, button hover effects, and transitions.
- JavaScript – DOM manipulation, variables, and event handling.

## Concepts Practised

- JavaScript variables (`let` and `const`).
- DOM manipulation using `document.getElementById()`.
- Event handling using `onclick`.
- Updating HTML content using `textContent`.
- CSS selectors and pseudo-classes.
- CSS transitions and transforms.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Use the Increase, Decrease, and Reset buttons to interact with the counter.

## Purpose

Built as a beginner JavaScript project to understand how JavaScript interacts with HTML elements and handles user interactions through DOM manipulation.
